# PhotoEdit

PhotoEdit is a planned free, native Kotlin Android app for image preparation and short-form video materials.

## Planned features
- Equal-grid photo splitting
- Batch image processing and export
- 9:16 vertical composition
- Pan-and-zoom videos from still images

## Technology
Kotlin, Jetpack Compose, Android Bitmap/Canvas, and (for later video work) OpenGL ES + MediaCodec. No paid API required for core features.

## Status
Project initialization in progress. An installable APK has **not** yet been built or tested.
