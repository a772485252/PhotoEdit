# PhotoEdit UI 设计与实现

先让用户顺利完成选图、调整、生成、检查和保存，再安排视觉层级。默认用中文解释关键取舍。本 skill 适用于本项目的每次 UI 改动；改一处文案时只检查受影响范围，不强行执行整套评审。

## 从实际行为出发

修改前阅读根目录 [AGENTS.md](../../../AGENTS.md)、[PROJECT.md](../../../PROJECT.md)、[PROGRESS.md](../../../PROGRESS.md) 最新记录和 [UI_DESIGN.md](../../../UI_DESIGN.md)。检查目标屏幕、MainActivity 容器、共享组件、主题及相关 ViewModel。不要把当前布局当成设计依据本身。

依据顺序：用户明确要求与业务正确性 → 项目已确认的控件规范 → Android / Material 3 习惯 → 视觉偏好。参考桌面设计方法时保留业务分析，重新判断手机触控、键盘和可用空间，不能直接复制侧栏或鼠标交互。

对本次涉及的关键操作，确认以下关系即可，不必为简单修改另建分析文档：

| 关系 | PhotoEdit 中需要确认的事实 |
| --- | --- |
| 输入与参数 | 当前处理哪张图、哪组照片、哪个平台/模型；切换后哪些结果失效 |
| 动作与副作用 | 选择不等于上传；带入提示词不等于生成；生成不等于保存到相册 |
| 结果与保存 | 当前显示的是新结果还是之前的结果；保存作用于哪一项或全部 |
| 等待与恢复 | 忙碌时哪些动作可用；停止本机等待不等于取消服务端任务 |

仅展示当前可用平台和已授权的功能。用户明确规划原型时可设计尚未实现的功能，但不能将原型入口当作已接通功能发布到应用中。UI 优化不能暗中改变模型、请求、计费、导出参数或持久化行为。

## 手机布局和控件

- 四个主功能保持可发现、可直接切换；键盘出现时优先留出输入与当前动作空间。导航不重建 ViewModel 或清空工作。
- 内容按当前任务组织：选择来源 → 调整参数 → 检查结果。需要反复查看的图像和参数保持容易返回，避免增加向导或标签层级。
- 主动作根据当前阶段确定。拆分、导出、生成和保存应明确区分；跨整个当前任务的动作可放在底部，局部动作靠近对象。
- 先预算 360dp 左右手机宽度，并检查更窄宽度、短屏、长中文和字体放大。这是设计检查场景，不是未经实测的适配承诺。
- 窄屏优先换行、上下排或使用已有菜单，不靠缩小字体容纳。少量互斥项直接可见；长候选列表使用下拉或独立选择区，只有真实查找需求才增加搜索。
- 明确滚动归属。聊天/图片历史滚动，输入区限制高度并可内部滚动；预览和大量照片放在内容区，不把它们全部固定在底部。
- 复用 Material 3 和 ui/theme、ui/components。相同用途和尺寸的按钮保持一致，不为每个区域增加配色或容器。共享组件只在确有重复且语义一致时提取。
- 触控操作通常保留约 48dp 可点击空间；图标操作有可读名称或语义描述。删除、上移和下移靠近当前照片，不能让动作挤掉标题和预览。

## 状态、信息和用户控制

- 区分未选择、当前选中、已生成、已保存。不要用同一个绿色或勾号代替这几种事实。
- 阻止下一步的条件、处理中状态、错误和恢复入口直接可见；常规说明、模型详细 ID 和长篇平台介绍按需展开。
- 成功结果已清楚显示时不再重复一段常驻说明。删除重复入口时确认原能力仍能到达。
- 付费生成前保留当前平台、模型和估价；估价不是实际扣费。保留凭据、权限和结果未知时必要的恢复提示，不添加每次请求都要点一次的重复确认。
- 错误保留安全的输入和选图；不能为了界面简洁移除真实的任务锁定或自动重试付费请求。
- 说明按钮为什么不可用，例如缺少图片、提示词或 Key。只显示当前状态需要的提示，不为所有理论异常堆占位文案。

## 轻量实现与验证

- Composable 只展示状态和发出回调；Bitmap、文件、网络、编码不移入 UI。UI 改动通常只涉及 ui/ 和必要的导航接线。
- 不过度防御：内部已保证的条件不逐层重复校验，不用兜底分支掩盖错误状态，不新增无依据的重试、恢复框架或额外确认。保留外部输入、文件/网络边界、重复提交和真实资源限制所需的校验。
- 不过度测试：纯文案、间距、颜色和可逆布局不新增机械断言、截图测试或大范围 mock。若改变关键业务规则，才补对应的小型确定性测试；保留现有有效测试。
- 优先复核完整任务路径：首次进入 → 输入/选择 → 执行 → 结果 → 保存；再检查本次相关的忙碌、失败、键盘和长内容状态。无需为不相关页面反复运行同一检查。
- 遵循 AGENTS.md 的构建授权规则。未请求 APK 时不触发构建；没有设备或运行环境时清楚记录静态审查范围，不能把源码检查称为编译通过或真机适配通过。
